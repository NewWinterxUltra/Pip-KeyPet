# Приложения-компаньоны Pip Link

iPhone работает с Пипом без приложения: Apple отдаёт уведомления, звонки и музыку через ANCS/AMS/CTS. Android и Windows таких системных BLE-сервисов не имеют, поэтому для полной связи нужна маленькая программа на телефоне или ПК.

- [apps/android](android) — APK для Android 8+ (уведомления, звонки, музыка, время).
- [apps/windows](windows) — программа для Windows 10/11 (уведомления, музыка, время).

Обе говорят с Пипом по одному протоколу Pip Link: [docs/companion.md](../docs/companion.md).

Без приложения с Android/Windows работают только пульт (мышь, Page Up/Down), медиа-клавиши и, на Android, кнопка громкости как затвор камеры.
