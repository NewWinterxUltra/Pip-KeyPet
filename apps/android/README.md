# Pip Link для Android

Приложение для телефона: передаёт Пипу уведомления, звонки, музыку и время по Bluetooth. Без него Android умеет только пульт, медиа-клавиши и (в некоторых камерах) кнопку громкости как затвор — системного BLE-сервиса уведомлений в Android нет.

## Установка

1. Собери APK (см. ниже) или возьми готовый `PipLink.apk`.
2. Открой APK на телефоне. Android спросит про установку из неизвестного источника — разреши для файлового менеджера/Chrome.
3. Запусти **Pip Link**.

## Первое подключение

1. Разреши уведомления, Bluetooth и телефон (кнопка «Разрешения»).
2. Нажми «Открыть доступ к уведомлениям» → найди **Pip Link** → включи.
   - Android 13+: если переключатель серый, открой «Настройки приложения» → ⋮ → **Разрешить ограниченные настройки**, потом вернись и включи доступ.
3. Нажми «Подключить Пипа».
4. На Пипе появится код — подтверди его **верхней кнопкой**.
5. В приложении статус станет «подключён», на Пипе — «телефон подключён».

## Что умеет

- Уведомления: приложение, заголовок, текст, время; убранные уведомления исчезают и на Пипе.
- Звонки: входящий звонок, ответить/отклонить с Пипа (нужны разрешения телефона; на некоторых прошивках OEM может не работать).
- Музыка: название, исполнитель, прогресс; play/pause, треки, громкость.
- Время и часовой пояс.
- Соблюдает режим приватности Пипа: при «выключено» текст уведомлений не передаётся.

## Чтобы работало в фоне

- Отключи оптимизацию батареи для Pip Link: «Настройки → Приложения → Pip Link → Батарея → Без ограничений».
- Не закрывай приложение из списка недавних; оно держит постоянное уведомление «Pip Link».
- На Xiaomi/Huawei/Samsung может понадобиться разрешить автозапуск.

## Сборка APK

Нужны JDK 17 и Android SDK 34.

```bash
cd apps/android
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Если Gradle ещё не установлен, открой папку `apps/android` в Android Studio (он сам скачает SDK и соберёт APK: Build → Build Bundle(s) / APK(s) → Build APK(s)).

## Ограничения

- Затвор камеры: Android не даёт приложению нажимать кнопку в чужой камере. Можно пользоваться HID-клавиатурой Пипа (кнопка громкости вверх) в приложениях камеры, которые это поддерживают.
- На Android 13+ установка из неизвестного источника требует «Разрешить ограниченные настройки» для доступа к уведомлениям.
- Некоторые производители убивают фоновые приложения; тогда помогает автозапуск и отключение оптимизации батареи.
