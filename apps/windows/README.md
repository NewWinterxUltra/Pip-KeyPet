# Pip Link для Windows

Маленькая программа, которая передаёт Пипу уведомления, музыку и время с Windows 10/11 по Bluetooth. Без неё Windows умеет только пульт и медиа-клавиши (HID), а уведомлений не будет: в Windows нет системного BLE-сервиса уведомлений, как ANCS у iPhone.

## Что нужно

- Windows 10 или 11 с Bluetooth LE.
- Python 3.9+ (если запускаешь из исходников) **или** готовый `PipLink.exe`.
- Прошивка Пипа с поддержкой Pip Link (эта папка).

## Запуск из исходников

```bat
cd apps\windows
python -m pip install -r requirements.txt
python pip_link.py
```

Откроется консоль с логом. Сверни её — программа работает в фоне.

## Первое подключение

1. Включи Bluetooth на ПК.
2. Запусти `pip_link.py` (или `PipLink.exe`).
3. Просни Пипа (коснись экрана).
4. Windows покажет запрос на сопряжение с кодом. На Пипе появится тот же код — нажми **верхнюю кнопку**, чтобы подтвердить.
5. В консоли появится `connected`, на Пипе — «телефон подключён».

Если Пип не находится: поднеси его ближе, проверь, что он не спит (в настройках брелока можно поставить «не засыпать»), и перезапусти программу.

## Что умеет

- Уведомления: приложение, заголовок, текст, время; удалённые уведомления исчезают и на Пипе.
- Музыка: название, исполнитель, прогресс; play/pause, следующий/предыдущий трек, громкость (если установлен `winsdk`, иначе — медиа-клавишами Windows).
- Время и часовой пояс — при подключении и раз в минуту.
- Соблюдает режим приватности Пипа: при «выключено» текст уведомлений не передаётся.

## Ограничения

- **Убрать уведомление с Пипа** можно, но оно не исчезнет из Центра уведомлений Windows: Windows не разрешает распакованной программе удалять чужие уведомления. На Пипе оно всё равно убирается.
- **Звонки** — не поддерживаются: в Windows нет системного API входящих звонков (кроме Phone Link, который не отдаёт их программно).
- Некоторые приложения не пишут уведомления в базу Windows (`wpndatabase.db`) — такие Пип не увидит.

## Сборка EXE

```bat
python -m pip install pyinstaller
pyinstaller --onedir --console --name PipLink --distpath dist --workpath build --specpath build pip_link.py
```

Готовый файл — `dist\PipLink\PipLink.exe` (папка `_internal` рядом обязательна). Его можно положить в автозагрузку:
`Win+R` → `shell:startup` → ярлык на EXE.

## Если не работает

- `bleak is not installed` — выполни `python -m pip install -r requirements.txt`.
- `Pip not found` — Пип спит или далеко; разбуди и подожди 10 секунд.
- Сопряжение не проходит — удали «Pip» в «Параметры → Bluetooth», перезапусти программу и подтверди код на Пипе верхней кнопкой.
- Нет уведомлений — проверь, что они вообще появляются в Центре уведомлений Windows; некоторые приложения (например, игры) их не показывают.
