# Pip Link: связь с Android и Windows

iPhone отдаёт уведомления, звонки и музыку через системные Apple-сервисы (ANCS, AMS, CTS) — приложению на телефоне ничего не нужно. **Android и Windows таких сервисов не выставляют.** Поэтому для полной связи нужна маленькая программа-компаньон: она читает уведомления/звонки/музыку у себя в системе и передаёт их Пипу по Bluetooth, а команды Пипа (открыть, ответить, следующий трек) выполняет обратно.

Без приложения с Android/Windows работает только то, что умеет любой Bluetooth-хост: пульт (мышь, Page Up/Down), медиа-клавиши и, на Android, кнопка громкости как затвор камеры.

## Что делает приложение

- подключается к Пипу по BLE (имя `Pip`);
- присылает время и часовой пояс;
- присылает уведомления, входящие звонки и состояние музыки;
- выполняет команды Пипа: убрать уведомление, ответить/отклонить звонок, play/pause, трек, громкость;
- соблюдает режим приватности Пипа: при «выключено» текст уведомлений не покидает телефон/ПК.

## BLE-сервис

Пип — периферия, приложение — централь. Сервис добавляется последним в таблицу GATT, чтобы не сдвигать handle'ы, которые закешировал iPhone.

| Что | UUID | Свойства |
|---|---|---|
| Сервис | `50495044-4247-4B45-5950-455400000010` | primary |
| RX (приложение → Пип) | `50495044-4247-4B45-5950-455400000011` | write, write without response |
| TX (Пип → приложение) | `50495044-4247-4B45-5950-455400000012` | notify |
| INFO | `50495044-4247-4B45-5950-455400000013` | read: `Pip companion 1` |

Соединение шифруется и бондится (numeric comparison: код показывается на Пипе, подтверждается верхней кнопкой). Одновременно могут быть подключены iPhone (ANCS), компьютер (HID-пульт) и приложение.

## Формат

Строки UTF-8, разделитель полей — `|`, конец строки — `\n`. Максимум 600 байт на строку. Символ `|` внутри текста заменяется на `/` отправителем; переводы строк — на пробел.

### Приложение → Пип

```
HELLO <platform> <appver>          platform: android | windows
TIME <unix_s> <tz_min>             время и зона (минуты восточнее UTC)
NOTE <uid>|<app>|<title>|<text>|<hh>|<mm>|<quiet>
NOTE_GONE <uid>
CALL <uid>|<name>|<kind>           входящий звонок
CALL_END
TRACK <title>|<artist>|<dur_s>|<pos_s>|<playing 0|1>
VOL <0..100>
PING
```

Примеры:

```
HELLO android 1.0
TIME 1794992400 180
NOTE 12345|Telegram|Аня|Встречаемся в 7 у входа?|14|27|0
CALL 777|Мама|мобильный
TRACK Nightcall|Kavinsky|258|102.5|1
```

`quiet=1` — уведомление не показывать баннером, только положить в список.

### Пип → приложение

```
OK HELLO 1
ERR <текст>
CMD DISMISS <uid>
CMD ANSWER <uid>
CMD DECLINE <uid>
CMD PLAY_PAUSE
CMD NEXT
CMD PREV
CMD VOL_UP
CMD VOL_DOWN
CMD SHUTTER
PRIVACY <0|1|2>                    0 открыто, 1 скрыто, 2 выключено
STATE <battery %|--> <0|1>         заряд и зарядка
PONG
```

При `PRIVACY 2` приложение не отправляет заголовок и текст — только имя приложения и время, а лучше вообще ничего, кроме звонков.

## Поведение

- Приложение подключается при старте, переподключается каждые 5 секунд, шлёт `TIME` при подключении и раз в минуту, `PING` раз в 30 секунд.
- `HELLO` — первый пакет после подписки на TX. До него Пип не считает связь установленной и не показывает «телефон подключён».
- Пип отвечает `STATE` и `PRIVACY` на `HELLO` и при изменении.
- Разрыв связи: Пип гасит признак «телефон подключён», если нет iPhone; приложение переподключается.
- Экономия энергии: когда экран Пипа спит, BLE выключается (`ble_quiet`); приложение увидит разрыв и переподключится, когда Пип проснётся.

## Приложения

- `apps/android` — Kotlin, Android 8+; NotificationListenerService, Telephony, MediaSession, BLE-клиент. Сборка: Android Studio или `./gradlew assembleDebug`.
- `apps/windows` — Python, Windows 10/11; база уведомлений `wpndatabase.db`, BLE через `bleak`. Запуск: `PipLink.exe` или `python pip_link.py`.

Подробности установки — в `apps/android/README.md` и `apps/windows/README.md`.
